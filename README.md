# Our First GitHub Collaboration

Welcome to our Bioinformatics GitHub activity!

## Objective

Learn how to use GitHub for version control and collaboration by contributing to a shared bioinformatics project.

**Duration:** 15 minutes

**Requirements:** A GitHub account and internet access.

No coding or software installation is required.

## Step 1 — Access the Repository

1. Sign in to your GitHub account.
2. Open the following repository:
   https://github.com/laaismarins/bioinformatics-practice

## Step 2 — Fork the Repository

1. Click **Fork** in the upper-right corner.
2. Select your account as the owner.
3. Keep the original repository name.
4. Keep **Copy the main branch only** selected.
5. Click **Create fork**.

You now have your own copy of the project.

## Step 3 — Create a New Branch

1. In your forked repository, click the **main** branch button.
2. Type a new branch name using your username.

   Example: `username-profile`

3. Click **Create branch**.
4. Make sure you are working on your new branch.

## Step 4 — Create Your Student Profile

1. Open the **STUDENTS** folder.
2. Click **Add file > Create new file**.
3. Name your file using your GitHub username.

   Example: `username.md`

4. Add the following information:

   # My Bioinformatics Profile

   Name: Your first name or username

   Research Interest: Your area of interest in Bioinformatics

Examples of research interests:
- Genomics
- Transcriptomics
- Neuroscience
- Proteomics
- Structural Bioinformatics
- Computational Biology

Note: This is a public repository. Do not include sensitive personal information.

## Step 5 — Commit Your Changes

1. Click **Commit changes**.
2. Enter a descriptive commit message:

   `Add my bioinformatics profile`

3. Select **Commit directly to your new branch**.
4. Click **Commit changes** to confirm.

You have now recorded your changes in the project's version history.

## Step 6 — Create a Pull Request

1. Click the **Pull requests** tab at the top-left of your forked repository, next to the Issues tab.
2. Click **New pull request**.
3. Check the following settings:

   - Base repository: YOUR fork
   - Base branch: main
   - Head repository: YOUR fork
   - Compare branch: username-profile

4. Click **Create pull request**.
5. Enter the following title:

   `Add my bioinformatics profile`

6. Click **Create pull request** to confirm.

IMPORTANT: For this step, both branches must belong to your own fork, not the original class repository.

## Step 7 — Review and Merge

1. Click **Files changed** to review your contribution.
2. Return to the **Conversation** tab.
3. Check for merge conflicts.
4. Click **Merge pull request**.
5. Click **Confirm merge**.

Congratulations! You have successfully merged your changes into your own main branch.

## Step 8 — Contribute to the Class Project

1. Return to your forked repository.
2. Switch to the **main** branch.
3. Click **Contribute > Open pull request**.
4. Check the following settings:

   - Base repository: laaismarins/bioinformatics-practice
   - Base branch: main
   - Head repository: YOUR fork
   - Compare branch: main

5. Click **Create pull request**.
6. Enter a descriptive title.
7. Click **Create pull request** to confirm.

Your contribution is now ready for the repository owner to review and merge.

## Learning Outcomes

By completing this activity, you will have practiced:

- Forking a repository
- Creating a branch
- Creating and editing files
- Committing changes
- Creating pull requests
- Reviewing changes
- Merging branches
- Contributing to a shared project
